# /kehoach — CẤM viết code trong lệnh này

Đọc `VIECDANGLAM.md`; rỗng ⇒ quay lại `ycau.md`.

1. Liệt kê CÁI CÓ SẴN dùng lại được, kể cả chỉ gần giống. Định viết hàm trùng vai, tạo file ở thư
   mục gốc, hay thêm thư viện ⇒ DỪNG HỎI, đừng ghi vào kế hoạch rồi làm luôn.
2. Trình user bằng ngôn ngữ thường, đúng 4 mục: **Làm gì** (từng bước, file nào bị đụng, vì sao
   file đó) · **Rủi ro** (có hỏng im lặng không; chạm dữ liệu thật ⇒ việc đứng riêng) · **Mất bao
   lâu** · **Lùi lại thế nào**. Kèm: **Lệnh nghiệm thu** sẽ chạy · **Test sẽ viết** (tên = câu
   luật) · **Có cần QD-nn không** (soạn sẵn dòng để duyệt luôn).
3. Nối `### Kế hoạch (duyệt <ngày>)` vào phiếu, giữ ≤ 14 dòng. DỪNG, chờ user gật đầu.
